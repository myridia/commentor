Comments that live outside the source file

commentor

A two-pane desktop viewer that pairs foo.rs with .comments.d/foo.rs.cmt. Read the source on the left, edit comments on the right, and follow the curves in the link strip between them.

Download latest View source

What it does

Two panes, one source

The wider left pane shows the read-only source; the right pane shows the editable comment file. Each source filename maps to .comments.d/<filename>.cmt.

Marker syntax

Blocks start with @N for one line or @N-M for an inclusive range. Line numbers are 1-based; everything up to the next marker belongs to that block.

Anchor-aware alignment

Markers can remember the source lines they describe. After code edits, Commentor finds moved, ambiguous or missing anchors and asks you to review the fix before saving.

Link strip

Two bezier curves per binding connect the first and last line of a comment block to its source range. A faint band shows the span; selecting a link brightens it.

Synchronized scrolling

Both panes scroll together through the mapped blocks. Click a highlighted line or a curve, or walk bindings with Next Link / Previous Link.

Markers stay hidden

The @ lines are hidden in the comment pane without changing line numbers, and restored when the file is saved. Separator lines stay untinted so sections read clearly.

Comment wrapping

Wrap long comment lines when you want. Gutter numbers, tint bands, link selection and scroll mapping all keep working in logical line numbers; the source stays unwrapped.

Syntax highlighting

A lightweight highlighter colours keywords, strings, comments, numbers, functions, types and macros. Auto-detects the language from the extension, with 14 languages and three palettes.

Themes & colours

Dark or light theme, accent schemes (blue, green, purple, warm, pink, neutral), configurable fonts, line numbers, link colours and spacing between sections.

Settings that persist

Preferences are saved to ~/.commentor/config.toml. The last successfully opened source path is remembered and reopened on startup, unless a path is passed as an argument.

Keyboard & menus

Classic File / Edit / View / Tools / Settings / Help menus, right-click editing on each pane, and shortcuts such as Ctrl+S to save comments.

How to use

  1. Open a source file with File → Open Source... or pass it as the first argument: cargo run -- path/to/foo.rs.
  2. Add a .comments.d/<filename>.cmt file beside it and write blocks starting with @N or @N-M.
  3. Edit the right pane; the source pane stays read-only. Use the link strip or Next / Previous Link to move between blocks.
  4. Edit the source elsewhere? Use View → Reload Source. If a block drifted, review the suggested lines in the alignment dialog.
  5. Save with File → Save Comments or Ctrl+S. Markers are preserved, and saving waits while an alignment review is open.

Try the bundled example: cargo run -- example/hello.rs.

Quick start

git clone https://github.com/myridia/commentor.git
cd commentor
cargo build --release
cargo run -- example/hello.rs

Built with Rust and eframe/egui 0.28.1 (wgpu). No database or async runtime required.
